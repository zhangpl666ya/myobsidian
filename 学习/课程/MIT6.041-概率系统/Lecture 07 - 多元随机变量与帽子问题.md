## 1. 多个随机变量：联合 PMF、条件、独立性

### 1.1 联合 PMF（Joint PMF）

对两个离散随机变量 $X$ 和 $Y$：

$$p_{X,Y}(x,y) = P(X=x \text{ 且 } Y=y)$$

### 1.2 边缘 PMF

从联合分布求出单个变量的 PMF：

$$p_X(x) = \sum_y p_{X,Y}(x,y)$$

$$p_Y(y) = \sum_x p_{X,Y}(x,y)$$

### 1.3 条件 PMF

$$p_{X \mid Y}(x \mid y) = \frac{p_{X,Y}(x,y)}{p_Y(y)}$$

同理：

$$p_{Y \mid X}(y \mid x) = \frac{p_{X,Y}(x,y)}{p_X(x)}$$

### 1.4 链式法则（Chain Rule）

三个随机变量的联合 PMF 可以展开为：

$$p_{X,Y,Z}(x,y,z) = p_X(x) \cdot p_{Y \mid X}(y \mid x) \cdot p_{Z \mid X,Y}(z \mid x,y)$$

这个公式告诉我们：**高维联合分布 = 边际 × 条件 × 条件**。

### 1.5 独立性

$X, Y, Z$ **互相独立**当且仅当：

$$p_{X,Y,Z}(x,y,z) = p_X(x) \cdot p_Y(y) \cdot p_Z(z), \quad \forall x,y,z$$

从联合PMF的角度，这意味着**联合分布可以分解为边际的乘积**。

### 1.6 例题：联合 PMF 表的独立性判断

| $p_{X,Y}(x,y)$ | $Y=1$ | $Y=2$ | $Y=3$ | $Y=4$ | $p_X(x)$ |
|----------------|-------|-------|-------|-------|---------|
| $X=1$ | $1/20$ | $2/20$ | $2/20$ | $2/20$ | $7/20$ |
| $X=2$ | $2/20$ | $4/20$ | $1/20$ | $2/20$ | $9/20$ |
| $X=3$ | $1/20$ | $3/20$ | $1/20$ | $1/20$ | $6/20$ |

**$X$ 与 $Y$ 是否独立？**

检验 $p_{X,Y}(x,y) \stackrel{?}{=} p_X(x) p_Y(y)$。例如 $p_{X,Y}(1,2) = 2/20$，而 $p_X(1) \cdot p_Y(2) = \frac{7}{20} \times \frac{9}{20} = \frac{63}{400}$，不相等 → **不独立**。

## 2. 多元期望

### 2.1 函数 $g(X,Y)$ 的期望

$$E[g(X,Y)] = \sum_x \sum_y g(x,y) \cdot p_{X,Y}(x,y)$$

注意：不能简化为 $g(E[X], E[Y])$。

### 2.2 线性性（无条件成立）

$$E[\alpha X + \beta Y + \gamma] = \alpha E[X] + \beta E[Y] + \gamma$$

注意：$E[X+Y] = E[X] + E[Y]$ **不要求 $X,Y$ 独立**。

### 2.3 独立时的特殊性质

若 $X$ 与 $Y$ **独立**：

$$E[XY] = E[X] \cdot E[Y]$$

$$E[g(X) \cdot h(Y)] = E[g(X)] \cdot E[h(Y)]$$

> **警告：** $E[XY] = E[X]E[Y]$ **等价于 $X,Y$ 不相关**，但独立和不相关不是一回事（独立 → 不相关，反之不一定成立）。

## 3. 方差的性质

| 公式 | 说明 |
|------|------|
| $\text{var}(aX) = a^2 \text{var}(X)$ | 常数提出平方 |
| $\text{var}(X + a) = \text{var}(X)$ | 加常数不改变方差 |
| $\text{var}(X + Y) = \text{var}(X) + \text{var}(Y) + 2\text{cov}(X,Y)$ | 一般公式 |
| 若 $X,Y$ **独立**：$\text{var}(X + Y) = \text{var}(X) + \text{var}(Y)$ | 协方差为零 |

### 例题：$Z = X + Y$，$X$ 与 $Y$ 独立

| 情况 | $X$ 与 $Y$ 关系 | $\text{var}(Z)$ |
|------|----------------|----------------|
| $X = Y$ | 完全正相关 | $\text{var}(X) + \text{var}(Y) + 2\text{var}(X) = 4\text{var}(X)$ |
| $X = -Y$ | 完全负相关 | $\text{var}(X) + \text{var}(Y) - 2\text{var}(X) = 0$ |
| $Z = X - 3Y$ | 独立时的线性组合 | $\text{var}(X) + 9\text{var}(Y)$ |

## 4. 二项分布的期望与方差（重新审视）

### 4.1 二项分布的分解

设 $X \sim \text{Binomial}(n,p)$，即 $X$ = $n$ 次独立伯努利试验中的成功次数。

定义 $X_i$：

$$X_i = \begin{cases} 1, & \text{第 } i \text{ 次试验成功} \\ 0, & \text{第 } i \text{ 次试验失败} \end{cases}$$

则：

$$X = X_1 + X_2 + \cdots + X_n$$

### 4.2 计算期望

每个 $X_i$ 服从参数为 $p$ 的伯努利分布：

$$E[X_i] = p, \quad \text{var}(X_i) = p(1-p)$$

利用线性性：

$$E[X] = E[X_1] + \cdots + E[X_n] = np$$

### 4.3 计算方差

由于各次试验独立：

$$\text{var}(X) = \text{var}(X_1) + \cdots + \text{var}(X_n) = np(1-p)$$

> **关键思想：** 把一个复杂的"总数"随机变量拆成 $n$ 个简单的"示性"随机变量之和，利用线性性绕过联合分布的复杂性。这个技巧是帽子问题的核心。

## 5. 帽子问题（Hat Problem）

### 5.1 问题描述

$n$ 个人把帽子扔进一个盒子里，然后**每个人随机取一顶**。设 $X$ = 最终拿到自己帽子的人数，求 $E[X]$。

### 5.2 示性变量分解

定义 $X_i$：

$$X_i = \begin{cases} 1, & \text{第 } i \text{ 个人拿到了自己的帽子} \\ 0, & \text{否则} \end{cases}$$

则：

$$X = X_1 + X_2 + \cdots + X_n$$

### 5.3 求 $E[X_i]$

每个人等概率地拿到某一顶帽子（共 $n$ 顶），所以：

$$P(X_i = 1) = \frac{1}{n}$$

因此：

$$E[X_i] = \frac{1}{n}$$

### 5.4 求 $E[X]$

利用线性性（**不要求 $X_i$ 之间独立**）：

$$E[X] = E[X_1] + \cdots + E[X_n] = n \cdot \frac{1}{n} = 1$$

**结论：无论 $n$ 多大，拿到自己帽子的人数的期望值总是 1。**

### 5.5 $X_i$ 之间真的独立吗？

**不独立。** 例如：当 $n=2$ 时，$X_1=1$（第一个人拿到自己的帽子）意味着第一个人拿了某顶，第二个人只能拿剩下的，所以 $X_2=1$（第二个人也拿到自己的帽子）→ $X_1$ 和 $X_2$ **完全相关**。

但这并不影响 $E[X] = E[X_1] + \cdots + E[X_n]$ 的计算，因为线性性对独立性没有要求。

---

## 6. 帽子问题的方差

要完整刻画 $X$ 的分布，除了期望还需要方差。但 $\text{var}(X)$ 的计算需要 $E[X_i X_j]$，这要求我们分析 $X_i$ 与 $X_j$ 的相关性。

### 6.1 展开 $\text{var}(X)$

$$\text{var}(X) = E[X^2] - (E[X])^2$$

$$X^2 = \left(\sum_i X_i\right)^2 = \sum_i X_i^2 + \sum_{i \neq j} X_i X_j$$

由于 $X_i^2 = X_i$（$X_i$ 是 0-1 变量）：

$$E[X^2] = \sum_i E[X_i] + \sum_{i \neq j} E[X_i X_j]$$

### 6.2 计算 $E[X_i X_j]$（$i \neq j$）

$$E[X_i X_j] = P(X_i = 1 \text{ 且 } X_j = 1)$$

第 $i$ 个人拿到自己帽子的同时，第 $j$ 个人也拿到自己的帽子——这要求第 $i$ 和第 $j$ 两个人**互相拿对**，而其他人任意。

在 $n$ 个人的随机排列中，这两个人互换了帽子，其他人可以任意排列：

$$P(X_i = 1 \text{ 且 } X_j = 1) = \frac{1}{n} \cdot \frac{1}{n-1}$$

验证：在 $n$ 个人的所有排列中，$i$ 拿到自己的帽子（第 $i$ 个位置固定为 $i$），$j$ 也拿到自己的帽子（第 $j$ 个位置固定为 $j$），其余 $n-2$ 人任意排列，概率为 $1 \times \frac{1}{n-1}$。

### 6.3 代入计算

$$E[X^2] = n \cdot \frac{1}{n} + n(n-1) \cdot \frac{1}{n(n-1)} = 1 + 1 = 2$$

$$\text{var}(X) = E[X^2] - (E[X])^2 = 2 - 1 = 1$$

**方差为 1**，有趣的是这与 $n$ 无关——无论多少人参与，拿到自己帽子的人数方差总是 1。

---

## 7. 帽子问题的底层逻辑：何时拆变量

### 7.1 核心特征

**可以用示性变量拆分的随机变量，通常具有以下特征：**

1. **"计数"型变量**：$X$ = 某种"成功"的总次数
2. **成功事件可以逐个定义**：每个基本单元是否"成功"可以被单独判断
3. **结构上可加**：$X$ 是多个独立/不独立的同类事件的总和

### 7.2 为什么要拆？

| 困难 | 拆解后的优势 |
|------|-------------|
| $X$ 的分布复杂，难以直接求 PMF | 每个 $X_i$ 是简单的伯努利/0-1 分布 |
| $X_i$ 之间不独立，方差叠加困难 | **线性性** $E[X] = \sum E[X_i]$ 完全不依赖独立性 |
| 直接计算 $\text{var}(X)$ 需要联合分布 | 用 $E[X_i X_j]$ 可以绕过，但仍有结构可利用 |

### 7.3 拆变量的通用模式

**适用于任意满足以下条件的 $X$：**

$$X = \sum_{i=1}^{n} X_i, \quad X_i \in \{0,1\}$$

即 $X$ 是 $n$ 个 0-1 示性变量的和。这种结构下：

$$E[X] = \sum_{i=1}^{n} E[X_i] = \sum_{i=1}^{n} P(X_i = 1)$$

**这个公式完全不需要 $X_i$ 独立。** 这就是为什么帽子问题可以绕过 $X_i$ 之间的相关性，直接得到 $E[X] = 1$。

### 7.4 关键识别题

看到一个计数型随机变量 $X$，问自己：

- $X$ 能否写成 $X_1 + X_2 + \cdots + X_n$？
- 每个 $X_i$ 是否是简单的 0-1 事件（伯努利）？

如果两者都满足，**示性变量拆解**就是首选方法，即使 $X_i$ 之间不独立也能轻松求出期望。

> **补充：** 方差的计算稍复杂一些，需要计算 $E[X_i X_j]$（$i \neq j$）。如果 $X_i$ 不独立，就需要用协方差公式：$\text{var}(X) = \sum \text{var}(X_i) + 2\sum_{i<j} \text{cov}(X_i, X_j)$。但帽子问题中，由于 $E[X_i X_j]$ 有明确的对称结构，方差也能算出来。

## 本讲要点

| 概念 | 公式 |
|------|------|
| 联合 PMF | $p_{X,Y}(x,y) = P(X=x, Y=y)$ |
| 边缘 PMF | $p_X(x) = \sum_y p_{X,Y}(x,y)$ |
| 条件 PMF | $p_{X \mid Y}(x \mid y) = p_{X,Y}(x,y) / p_Y(y)$ |
| 独立性 | $p_{X,Y,Z} = p_X p_Y p_Z$ |
| 期望线性性 | $E[X+Y] = E[X] + E[Y]$（不需要独立） |
| 独立时 | $E[XY] = E[X]E[Y]$ |
| $\text{var}(X+Y)$（独立）| $\text{var}(X) + \text{var}(Y)$ |
| 二项分布 | $E[X] = np$，$\text{var}(X) = np(1-p)$ |
| 帽子问题 | $E[X] = 1$，$\text{var}(X) = 1$ |

---

## 核心思想

1. **联合分布是基础**：一切多元随机变量的问题从联合 PMF 出发
2. **线性性不问出处**：$E[X+Y] = E[X]+E[Y]$ 无条件成立，是最重要的期望性质之一
3. **拆变量是为了绕过复杂性**：把一个难求的总数变量拆成简单的示性变量之和，利用线性性绕过联合分布的复杂性
4. **示性变量法的适用范围**：计数型变量 + 0-1 事件 + 可加结构 = 直接用期望的线性性，不需要独立性
