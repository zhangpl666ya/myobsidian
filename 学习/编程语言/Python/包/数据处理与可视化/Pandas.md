# 创建和观察DataFrame
```python
import pandas as pd

# 1. Prepare raw matrix values (mixed tracking data)
sales_data = [
    ['Dept-A', 150, 115.5],
    ['Dept-B', 200, 87.0],
    ['Dept-C', 100, 60.5],
    ['Dept-D', 112, 140.0]
]

# 2. Define row identifiers and column descriptions
store_names = ['Store_1', 'Store_2', 'Store_3', 'Store_4']
metrics = ['Department', 'Units_Sold', 'Profit_Margin']

# 3. Create the unified DataFrame
df = pd.DataFrame(data=sales_data, index=store_names, columns=metrics)

print("--- Our Pandas Sales Dashboard DataFrame ---")
print(df)

print("\nRow Indexes:", list(df.index))      # Access row names 
print("Column Names:", list(df.columns))   # Access column attributes 
print("Raw NumPy Matrix Behind It:\n", df.values) # Extracts underlying ndarray 
print("Underlying Type of Matrix Values:", type(df.values)) #
```
- 这里先准备表格数据`sales_data`
- 然后用list由上到下存储每一行的名字
- 用list存储每一列的名字
- 创建一个DataFrame需要三个参数，这些东西的size要对齐。
- 用`df.index`和`df.columns`获取行列名称。

# `groupby()`分组

理解 `groupby` 的核心，其实就是一句话——**“分、配、合”（Split-Apply-Combine）**。我们可以把它想象成一个“水果分类打包”的过程。

## 1. 核心三步走逻辑

假设我们有一张记账单，里面有“类别”（餐饮、交通、购物）和“金额”。

```
   类别   金额
0  餐饮   20
1  交通   10
2  餐饮   30
3  购物  100
```

当你执行 `df.groupby('类别')` 时，Pandas 在幕后做了三件事：

```
1. 分 (Split)   ：按“类别”把数据切开，分成 餐饮组、交通组、购物组。
2. 配 (Apply)   ：把你想要的数学公式（比如求和 sum）应用到每一组的“金额”上。
3. 合 (Combine) ：把每组算出来的结果重新拼成一张新表。
```

最后吐给你的结果就是：餐饮 50，交通 10，购物 100。

## 2. 最常用的几种用法

我们来看看 `groupby` 的几种常见姿势：

### ① 基础款：单列分组，单列聚合

这是最常用的。比如：计算每个**记账标签**的总花销。

```python
# 按照“类别”分组，算“金额”的总和
df.groupby('类别')['金额'].sum()
```

### ② 进阶款：一次性看多个统计指标（`.agg()`）

有时候你不仅想知道每类花了多少钱，还想知道**花了几笔（count）**、**平均每笔花多少（mean）**。这时候就要请出 `.agg()`（Aggregate 的缩写）：

```python
# 传入一个列表，同时计算总和与平均值
df.groupby('类别')['金额'].agg(['sum', 'mean', 'count'])
```

### ③ 豪华款：不同列用不同的计算规则

假设你的表里既有“金额”，又有“报销比例”。你想算**金额的总和**，同时想算**报销比例的平均值**：

```python
# 传入一个字典，给不同的列指定不同的函数
df.groupby('类别').agg({
    '金额': 'sum',
    '报销比例': 'mean'
})
```



# `groupby()`分组进阶
这正是 `groupby` 威力全开的时候了！当你要**同时按多个标准分组，并且针对不同的列做不同的计算**，我们只需要把刚才讲的 **双重分组** 和 **字典聚合（`.agg()`）** 结合起来。

我们直接用一个具体的“进阶版记账本”来看看怎么操作：

### 📁 假设你的记账本数据长这样：

|**月份**|**账户 (标准2)**|**金额 (数据1)**|**商家 (数据2)**|**备注**|
|---|---|---|---|---|
|5月|微信支付|50|麦当劳|晚饭|
|5月|微信支付|20|7-11|零食|
|5月|支付宝|100|盒马|买菜|
|6月|微信支付|15|自动贩卖机|饮料|

### 🛠 你的需求：按“月份”和“账户”双重分组，同时对“金额”求和，对“商家”统计消费次数。

代码实现非常优雅，直接给 `.agg()` 传一个字典就行：

```python
import pandas as pd

# 1. 按照多个标准分组（传入列表）
grouped = df.groupby(['月份', '账户'])

# 2. 针对不同的列，各玩各的规则（传入字典）
result = grouped.agg({
    '金额': 'sum',      # 金额那一列，我们要看总花销
    '商家': 'count'    # 商家那一列，我们要看消费了多少次
})

# 3. 习惯性把索引拉平，变成好看的普通表格
result = result.reset_index()

print(result)
```

### 📊 打印出来的结果会是这样：

|       | **月份** | **账户** | **金额** | 商家  |
| ----- | ------ | ------ | ------ | --- |
| **0** | 5月     | 支付宝    | 100    | 1   |
| **1** | 5月     | 微信支付   | 70     | 2   |
| **2** | 6月     | 微信支付   | 15     | 1   |

### 🔥 还能玩得更绝：同一列同时做多种计算

如果你不仅想知道 5 月微信支付的**总金额**，还想知道**最大的一笔是多少**，甚至**平均每笔是多少**，字典里还可以套列表：

```python
result = df.groupby(['月份', '账户']).agg({
    '金额': ['sum', 'max', 'mean'],  # 一口气算出总和、最大值、平均值
    '商家': 'count'
})
```


## 💡 容易踩的两个小坑（避坑指南）

1. **分组后它不是 DataFrame 了？**
    
    如果你写 `df.groupby('类别')['金额'].sum()`，返回的通常是一个 `Series`（只有一列数据加一个索引）。如果你希望它保持好看的 `DataFrame` 格式，可以在最后加一个 `.reset_index()`，或者在 groupby 里面加上 `as_index=False`：

```python
    # 这样返回的就是一个标准的平铺 DataFrame
    df.groupby('类别', as_index=False)['...'].sum()
```

2. **直接 print(df.groupby('列名')) 怎么什么都没有？**
    
    如果你只写到 `df.groupby('类别')` 就去 `print`，你会看到一行类似 `<pandas.core.groupby...>` 的怪东西。这是因为 Pandas 很懒，你**只分了组，没告诉它怎么计算（没写 sum/mean 等）**，它就停在那里不干活。后面必须接一个聚合函数，它才会真正执行。
