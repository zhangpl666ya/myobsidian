`panda`以下简称pd
其用一种数据结构`DataFrame`来存储数据，这是一张二维表格，想象成excel表格，每一列像一维数组一样处理，叫做`series`

# 创建和观察DataFrame
```python
import pandas as pd

# 1. Prepare raw matrix values (mixed tracking data)
sales_data = [
    ['Dept-A', 150, 115.5],
    ['Dept-B', 200, 87.0],
    ['Dept-C', 100, 60.5],
    ['Dept-D', 112, 140.0]
]

# 2. Define row identifiers and column descriptions
store_names = ['Store_1', 'Store_2', 'Store_3', 'Store_4']
metrics = ['Department', 'Units_Sold', 'Profit_Margin']

# 3. Create the unified DataFrame
df = pd.DataFrame(data=sales_data, index=store_names, columns=metrics)

print("--- Our Pandas Sales Dashboard DataFrame ---")
print(df)

print("\nRow Indexes:", list(df.index))      # Access row names 
print("Column Names:", list(df.columns))   # Access column attributes 
print("Raw NumPy Matrix Behind It:\n", df.values) # Extracts underlying ndarray 
print("Underlying Type of Matrix Values:", type(df.values)) #
```
- 这里先准备表格数据`sales_data`
- 然后用list由上到下存储每一行的名字
- 用list存储每一列的名字
- 创建一个DataFrame需要三个参数，这些东西的size要对齐。
- 用`df.index`和`df.columns`获取行列名称。

# 数据处理与错误
```python 
# Create a brand new column instantly by applying a scalar to an existing series column
df['Wholesale_Cost'] = df['Units_Sold'] * 10.0

# Combine two Series columns using vectorized element-wise math!
# Estimated Revenue = Wholesale Cost + Profit Margin
df['Est_Revenue'] = df['Wholesale_Cost'] + df['Profit_Margin']

print("--- Dashboard Matrix with Computed Metrics ---")
print(df)

import numpy as np

# Let's dynamically add a new broken store location row using .loc
# We intentionally pass np.nan to simulate missing data for Profit Margin
df.loc['Store_5'] = ['Dept-A', 80, np.nan]

print("\n--- Dashboard Table with a Corrupted Row (Store_5) ---")
print(df)

# Check if a specific cell contains a missing element
print("\nIs Store_5's Profit Margin missing?:", pd.isnull(df.loc['Store_5', 'Profit_Margin'])) [cite: 6]

# Instead of letting NaN poison our calculations, fill all NaNs with a fallback value (0.0)
# inplace=True mutates the underlying DataFrame object immediately without needing an assignment statement
df.fillna(0, inplace=True) [cite: 6]

print("\n--- Cleaned Dashboard Table (NaNs Overwritten with 0) ---")
print(df)

print("\n--- Final Corporate Performance KPIs ---")
print("Total Global Units Sold:", df['Units_Sold'].sum())
print("Average Profit Margin achieved:", df['Profit_Margin'].mean())
print("Maximum Revenue generated by a single store:", df['Est_Revenue'].max())
```
- 取出的列都是向量，所以遵循向量的数乘与加减。
- df的特性跟字典一样，若索引的内容不存在就创建新的列。
- 这里缺失的数据会在打印时用NaN显示。
- 用`isnull()`检查数据是否丢失
- 用`.fillna()`将空的位置填上指定数字。
- `inplace=True`df中的所有操作其实是返回一个操作过后的副本，原来的没改，用这个参数可以直接在原来内容上修改
- 有内置函数，求和、平均值、最大小值
