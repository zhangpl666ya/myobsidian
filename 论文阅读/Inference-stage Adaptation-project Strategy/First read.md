# 1. Abstract（摘要）怎么读

## 阅读目标：

不要试图理解细节，只回答：

> 这篇论文想解决什么大问题？

填空：

```
这篇论文研究的问题是：

过去的方法主要存在的问题是：

作者提出的方法叫：

核心思想是一句话：

作者声称取得的效果：

```
# 2. Introduction（引言）

这是论文最重要部分。

不要急着看公式。

读 Introduction 时，画一条逻辑链：

```
现实问题
    ↓
已有方法
    ↓
已有方法为什么失败
    ↓
作者提出新方向
```
