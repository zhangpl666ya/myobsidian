## 第一部分：概率基础（讲1–4）

### 讲1 概率模型与公理
- 样本空间（Sample Space）、Outcome、概率测度
- 概率三公理：非负、归一、可列可加
- 条件概率、全概率公式、贝叶斯公式

### 讲2 条件概率与贝叶斯法则
- 条件概率定义与乘法定理 $P(A \mid B) = P(A \cap B) / P(B)$
- 全概率公式
- **贝叶斯法则** — 贯穿整个课程的核心工具

### 讲3 独立性
- 两个事件独立：$P(A \cap B) = P(A)P(B)$
- 条件独立：$P(A \cap B \mid C) = P(A \mid C)P(B \mid C)$
- 独立重复试验（Bernoulli Trials）

### 讲4 计数原理
- 排列（Arrangements）、组合（Combinations）
- 加法/乘法法则、二项式系数 $\binom{n}{k}$
- 解决"概率怎么算"的问题

> **学习提示：** 前四讲是整门课的基础工具箱。贝叶斯公式和计数是后续几乎所有内容的前置知识，务必熟练。

## 第二部分：离散随机变量（讲5–7）

### 讲5 随机变量
- 随机变量定义：函数 $X: \Omega \to \mathbb{R}$
- **PMF（概率质量函数）**：$p_X(x) = P(X=x)$，满足 $\sum_x p_X(x) = 1$
- **几何分布**（Geometric）：$p_X(k) = (1-p)^{k-1}p$，$k=1,2,\ldots$，期望 $E[X]=1/p$
- **二项分布**（Binomial）：$X \sim \text{Binomial}(n,p)$，$p_X(k) = \binom{n}{k}p^k(1-p)^{n-k}$
- **期望** $E[X] = \sum_x x \cdot p_X(x)$
- **方差** $\text{var}(X) = E[X^2] - (E[X])^2$
- 关键警告：**$E[g(X)] \neq g(E[X])$**

### 讲6 联合分布与条件PMF
- **联合PMF**：$p_{X,Y}(x,y) = P(X=x, Y=y)$
- 边缘PMF：$p_X(x) = \sum_y p_{X,Y}(x,y)$
- 条件PMF：$p_{X \mid Y}(x \mid y) = p_{X,Y}(x,y) / p_Y(y)$
- **全期望定理**：$E[X] = \sum_i P(A_i) E[X \mid A_i]$
- 几何分布的**无记忆性**（Memoryless）：$P(X > s+t \mid X > s) = P(X > t)$
- 例：平均速度 vs. 穿越时间（$E[200/V] \neq 200/E[V]$ 的反面教材）

### 讲7 多元随机变量、期望、帽子问题
- 三个及以上随机变量的联合PMF
- 独立性的判定：$p_{X,Y,Z}(x,y,z) = p_X(x) p_Y(y) p_Z(z)$
- 期望的线性性：**无条件成立** $E[X+Y] = E[X]+E[Y]$
- 若 $X,Y$ 独立，则 $E[XY] = E[X]E[Y]$
- 方差的叠加（独立时）：$\text{var}(X+Y) = \text{var}(X) + \text{var}(Y)$
- **帽子问题**（Hat Problem）：用示性变量 $X_i$ 把复杂计数拆成简单期望之和的经典技巧

> **学习提示：** 讲5–7 是整个课程最核心的部分。PMF、期望、方差、独立性、几何分布——这些是后面一切的基石。帽子问题的示性变量技巧（$X = X_1 + \cdots + X_n$）在马尔可夫链和统计推断里反复出现。

## 第三部分：连续随机变量（讲8–12）

### 讲8 连续随机变量
- **PDF（概率密度函数）**：$f_X(x) \geq 0$，$\int_{-\infty}^{+\infty} f_X(x)dx = 1$
- **注意**：PDF 是密度，不是概率；$P(a \leq X \leq b) = \int_a^b f_X(x)dx$
- 均匀分布、指数分布（无记忆性）
- 连续变量的期望：$E[X] = \int_{-\infty}^{+\infty} x f_X(x)dx$

### 讲9 多个连续随机变量
- 联合PDF：$f_{X,Y}(x,y)$
- 边缘PDF：$f_X(x) = \int f_{X,Y}(x,y)dy$
- 条件PDF：$f_{X \mid Y}(x \mid y) = f_{X,Y}(x,y) / f_Y(y)$
- 独立性的判定

### 讲10 连续贝叶斯法则与导出分布
- 连续条件概率
- **导出分布**（Derived Distribution）：已知 $Y = g(X)$，求 $f_Y$
- 变换公式（Change of Variable）

### 讲11 卷积、协方差与相关性
- 卷积（Convolution）：$Z = X+Y$ 的分布 $f_Z(z) = \int f_{X,Y}(x, z-x)dx$
- **协方差**：$\text{cov}(X,Y) = E[XY] - E[X]E[Y]$
- **相关系数**：$\rho_{X,Y} = \text{cov}(X,Y) / (\sigma_X \sigma_Y)$
- 独立 → 不相关（但反之不一定）

### 讲12 条件期望与迭代期望
- 条件期望 $E[X \mid Y=y]$：是 $y$ 的函数，本质是随机变量
- **迭代期望定律**：$E[E[X \mid Y]] = E[X]$（最常用的概率工具之一）
- **全方差公式**：$\text{var}(X) = E[\text{var}(X \mid Y)] + \text{var}(E[X \mid Y])$
- 这两个公式在马尔可夫链和统计推断中反复出现

> **学习提示：** 从离散过渡到连续。关键难点：①PDF 是密度而非概率；②卷积计算；③条件期望作为随机变量。迭代期望定律和全方差公式要彻底搞懂。

## 第四部分：随机过程与统计推断（讲13–25）

### 讲13–15 伯努利过程与泊松过程

| | 伯努利过程 | 泊松过程 |
|---|---|---|
| 类型 | 离散时间 | 连续时间 |
| 事件发生 | 每次试验成功概率 $p$ | 率为 $\lambda$ 的指数间隔 |
| 计数分布 | 二项分布 $B(n,p)$ | 泊松分布 $P(\lambda t)$ |
| 间隔时间 | 几何分布（离散） | 指数分布（连续） |
| 无记忆性 | ✅ | ✅ |

- **泊松过程三大特征**：时间齐次、独立增量、小区间近似 $P(\text{1 event in } \delta) \approx \lambda \delta$
- 泊松作为二项分布的极限：$n \to \infty, p \to 0, np = \lambda$
- 第 $k$ 次到达时间：Erlang 分布（Gamma 分布的特殊情况）
- **合并与分裂**：独立泊松过程之和仍为泊松；每个事件以概率 $p$ 选择分支后，两个输出流也是泊松过程（率分别为 $\lambda p$ 和 $\lambda(1-p)$）
- **随机到达（Random Incidence）**：随机出现在泊松过程时间线上，你所在的间隔长度分布是"大小偏倚"分布，期望值是普通间隔的 **2 倍**

> **学习提示：** 泊松过程是概率论中最重要的随机过程之一。反直觉的随机到达结论是高频考点。

### 讲16–18 马尔可夫链（三讲）

**讲16 马尔可夫链基础**
- 离散时间、有限状态空间、转移概率 $p_{ij}$
- 马尔可夫性：$P(X_{n+1}=j \mid X_n=i, \ldots) = p_{ij}$
- $n$ 步转移概率 $r_{ij}(n)$，递推：$r_{ij}(n) = \sum_k r_{ik}(n-1) p_{kj}$
- **常返（Recurrent）vs 瞬态（Transient）**

**讲17 稳态收敛**
- 若链是单个非周期常返类，则 $r_{ij}(n) \to \pi_j$（与初始状态无关）
- **平衡方程**：$\pi_j = \sum_i \pi_i p_{ij}$，$\sum_j \pi_j = 1$
- 物理含义：长期处于状态 $j$ 的频率等于 $\pi_j$
- **生灭过程**（Birth-Death Process）：有闭式解 $\pi_i = \pi_0 \rho^i$

**讲18 吸收概率与期望吸收时间**
- 吸收概率 $a_i$（从状态 $i$ 最终进入某吸收态）
- 期望吸收时间 $\mu_i$
- 首达时间与回访时间

> **学习提示：** 马尔可夫链是很多高级课程的入口（随机过程、排队论、金融工程）。重点：状态分类、平衡方程求 $\pi_j$、吸收概率的线性方程组求解。

### 讲19–20 大数定律与中心极限定理

**讲19 弱大数定律（WLLN）**
- i.i.d. 样本均值 $M_n = (X_1+\cdots+X_n)/n$
- $M_n \to \mu$（依概率收敛）
- 切比雪夫不等式：$P(|X-\mu| \geq c) \leq \sigma^2/c^2$

**讲20 中心极限定理（CLT）**
- $\frac{M_n - \mu}{\sigma/\sqrt{n}} \to N(0,1)$（依分布收敛）
- **这是概率论最重要的定理**：大量小独立效应之和趋近正态分布
- 用途：近似计算二项分布（$n$ 大时）、构造置信区间

> **学习提示：** CLT 是统计推断的基石——它解释为什么正态分布在自然界如此普遍。

### 讲21–25 统计推断（最后五讲）

从概率论过渡到统计学。

**讲21 贝叶斯统计框架**
- 两种范式：**贝叶斯**（$\Theta$ 是随机变量）vs **经典统计**（$\Theta$ 是固定常数）
- 贝叶斯推断：先验 $p_\Theta(\theta)$ + 数据 $X$ → 后验 $p_{\Theta \mid X}(\theta \mid x) = \frac{p_\Theta(\theta) p_{X \mid \Theta}(x \mid \theta)}{p_X(x)}$
- **后验分布**是贝叶斯统计的核心输出

**讲22 估计方法**
- **点估计**：给定数据 $X$，估计未知参数 $\Theta$
- **MAP 估计**：$\hat{\theta} = \arg\max p_{\Theta \mid X}(\theta \mid x)$（后验最大化）
- **LMS（最小均方误差）估计**：$\hat{\Theta} = E[\Theta \mid X]$（条件均值）
- 重要性质：LMS 估计无偏，$E[\tilde{\Theta} \cdot h(X)] = 0$；$\text{var}(\Theta) = \text{var}(\hat{\Theta}) + \text{var}(\tilde{\Theta})$
- **线性 LMS**：形式限制为 $\hat{\Theta} = aX + b$

**讲23 经典统计：最大似然估计（MLE）**
- 经典范式：$\theta$ 是未知常数，$\hat{\theta}_{ML} = \arg\max p_X(x; \theta)$
- MLE 性质：**一致性**（$n \to \infty$ 时收敛到真值）、**渐进正态性**
- **置信区间**：用 CLT 构造 $\hat{\Theta}_n \pm z_{\alpha/2} \cdot \sigma/\sqrt{n}$

**讲24 线性回归与二元假设检验**
- **线性回归**：$\hat{\theta}_1 = \frac{\text{cov}(X,Y)}{\text{var}(X)}$
- **二元假设检验**：$H_0$（原假设）vs $H_1$（备择假设）
- 两类错误：第一类错误 $\alpha$（$H_0$ 为真但被拒绝）、第二类错误 $\beta$（$H_0$ 为假但被接受）
- **似然比检验（LRT）**：拒绝 $H_0$ 当 $\frac{p(x;H_1)}{p(x;H_0)} > \xi$

**讲25 复合假设检验与课程总结**
- 复合假设：$H_0$ 或 $H_1$ 是参数集合，不是一个分布
- 硬币是否公平的检验（CLT 近似）
- **卡方检验**（Chi-square Test）：检验离散分布
- 柯尔莫哥洛夫-斯米尔诺夫检验（K-S 检验）：检验连续分布
- 课程全面回顾

## 常见难点与学习建议

| 阶段 | 重点 | 难度 |
|------|------|------|
| 讲1–4 | 贝叶斯公式、计数 | ⭐ |
| 讲5–7 | PMF、期望方差、独立性、帽子问题 | ⭐⭐ |
| 讲8–12 | 连续变量、卷积、条件期望、全方差公式 | ⭐⭐⭐ |
| 讲13–15 | 泊松过程（合并/分裂/随机到达） | ⭐⭐⭐ |
| 讲16–18 | 马尔可夫链（平衡方程、吸收概率） | ⭐⭐⭐⭐ |
| 讲19–20 | WLLN、CLT | ⭐⭐⭐ |
| 讲21–25 | 贝叶斯推断、MLE、回归、假设检验 | ⭐⭐⭐⭐ |

**最容易卡住的地方：**

1. **条件期望作为随机变量**（讲6、12）  
   $E[X \mid Y]$ 本身是随机变量，随 $Y$ 的取值而变化，不是具体数值

2. **迭代期望定律** $E[E[X \mid Y]] = E[X]$（讲12）  
   看似简单，但在复杂问题中容易用错

3. **马尔可夫链的平衡方程**（讲17）  
   求解 $\pi_j$ 时不要忘记归一化条件 $\sum_j \pi_j = 1$

4. **中心极限定理的应用**（讲20、24）  
   用 CLT 近似二项分布或构造置信区间是高频考点
