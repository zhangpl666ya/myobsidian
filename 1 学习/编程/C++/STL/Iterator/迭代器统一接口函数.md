# 一、这类函数在标准中的定位

`advance / distance / next / prev` 并不是“普通工具函数”，而是：

> **对“迭代器能力差异”的统一抽象接口**

它们的核心思想是：

- **接口统一**
    
- **实现根据 iterator category 自动选择最优策略**
    

这正是 C++ 迭代器设计的精华。

---

# 二、std::advance —— “让迭代器走 N 步”

## 1️⃣ 函数原型

```cpp
template<class InputIt, class Distance>
void advance(InputIt& it, Distance n);
```

📌 **注意**

- 传入的是 **引用**
    
- 会 **直接修改 it**
    
- 不返回值
    

---

## 2️⃣ 不同迭代器下的真实行为（核心）

### 🔹 Input / Forward Iterator

```cpp
while (n-- > 0)
    ++it;
```

- 只能 `++`
    
- **线性时间 O(n)**
    
- n **必须 ≥ 0**
    

📌 例子：

```cpp
forward_list<int> fl;
auto it = fl.begin();
advance(it, 10);   // 只能一个一个 ++
```

---

### 🔹 Bidirectional Iterator

```cpp
if (n >= 0)
    while (n--) ++it;
else
    while (n++) --it;
```

- 支持负数
    
- 仍然是 **O(|n|)**
    

📌 例子：

```cpp
list<int> lst;
advance(it, -3);   // 合法
```

---

### 🔹 Random Access Iterator（关键优化）

```cpp
it += n;
```

- **O(1)**
    
- 这就是 `vector` 快的根本原因
    

📌 例子：

```cpp
vector<int> v;
auto it = v.begin();
advance(it, 1'000'000); // 常数时间
```

---

## 3️⃣ 典型坑点

### ❌ 对 Input Iterator 使用负数

```cpp
istream_iterator<int> it;
advance(it, -1);   // ❌ 未定义行为
```

---

### ❌ 误以为 advance 有返回值

```cpp
auto it2 = advance(it, 5); // ❌
```

---

## 4️⃣ 什么时候必须用 advance？

- 写 **模板算法**
    
- 不知道迭代器类型
    
- 想获得“最优复杂度”

# 三、std::distance —— “两个迭代器之间有多远”

## 1️⃣ 函数原型

```cpp
template<class InputIt>
typename iterator_traits<InputIt>::difference_type
distance(InputIt first, InputIt last);
```

📌 **重要**

- 不修改参数
    
- 返回值类型是 `difference_type`
    

---

## 2️⃣ 不同迭代器下的实现差异

### 🔹 Input / Forward / Bidirectional

```cpp
difference_type n = 0;
while (first != last) {
    ++first;
    ++n;
}
return n;
```

- **O(n)**
    
- 必须一步步走
    

📌 容器：

- `list`
    
- `forward_list`
    
- `set / map`
    

---

### 🔹 Random Access Iterator（关键）

```cpp
return last - first;
```

- **O(1)**
    

📌 容器：

- `vector`
    
- `deque`
    
- `array`
    

---

## 3️⃣ 非常重要的语义限制

### ⚠️ distance 对 Input Iterator 是“消耗性”的

```cpp
istream_iterator<int> a, b;
auto n = distance(a, b); // a 被走到 b
```

📌 **这是标准允许的**

👉 Input Iterator 只保证一次遍历

---

## 4️⃣ 常见误解

### ❌ 以为 list::size() 和 distance 一样快

```cpp
distance(lst.begin(), lst.end()); // O(n)
lst.size();                       // C++11 起是 O(1)
```

---

# 四、std::next / std::prev —— advance 的安全封装

## 1️⃣ std::next

```cpp
template<class It>
It next(It it, difference_type n = 1);
```

等价于：

```cpp
It tmp = it;
advance(tmp, n);
return tmp;
```

📌 **不修改原迭代器**

---

## 2️⃣ std::prev

```cpp
template<class It>
It prev(It it, difference_type n = 1);
```

📌 **要求 Bidirectional 以上**

---

### 使用示例

```cpp
auto it2 = next(it, 5);   // 安全
auto it1 = prev(it, 2);   // 必须支持 --
```

---

# 五、advance / distance 与算法性能的决定性关系

## 例子 1：为什么 sort 不能用于 list？

```cpp
sort(lst.begin(), lst.end()); // ❌
```

原因：

- `sort` 内部大量使用：
    
    - `it + n`
        
    - `it2 - it1`
        
- 需要 **Random Access Iterator**
    

---

## 例子 2：为什么 nth_element 很快？
（nth_element用于查找第k大/小的元素）
```cpp
nth_element(v.begin(), v.begin() + k, v.end());
```

📌 依赖：

- O(1) 的 `advance`
    
- O(1) 的 `distance`

# 六、iterator_traits：这一切的幕后黑手

```cpp
iterator_traits<It>::iterator_category
```

标准内部做的事情大致是：

```cpp
if constexpr (is_random_access_iterator<It>)
    it += n;//Random Access Iterator
else
    while (n--) ++it;//else
```
trait会自动识别迭代器类型并找到对应函数接口

👉 **advance / distance 是 traits + tag dispatch 的经典应用**

# 七、终极对照表（核心记忆）

|函数|Input|Forward|Bidirectional|Random Access|
|---|---|---|---|---|
|advance(it, +n)|✔|✔|✔|✔ (O1)|
|advance(it, -n)|✘|✘|✔|✔|
|distance|O(n)|O(n)|O(n)|O(1)|
|next|✔|✔|✔|✔|
|prev|✘|✘|✔|✔|

---

# 八、一句话总结（高级理解）

> **advance / distance 并不是“帮你写循环”**  
> **而是：让算法“在不知道迭代器类型的情况下仍然做到最优复杂度”**
