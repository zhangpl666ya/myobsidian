## 📅 分阶段通关建议

### 🟢 阶段一：夯实基石（建议耗时：2-3个月）

- **行动指南**：在这个阶段，**数学甚至比写代码更重要**。
    
- **重点**：18.06 的矩阵变换（SVD是重中之重），以及 6.041 中的贝叶斯定理和最大似然估计。6.0001 如果你有 Python 基础可以直接跳过。
    

### 🟡 阶段二：打通枢纽（当前阶段，建议耗时：2-3个月）

- **课程**：**[[1 学习/MIT/MIT6.006/README|6.006 算法导论]]**
    
- **行动指南**：不要陷入纯理论的泥潭。重点攻克 **图论（BFS/DFS/Dijkstra）** 和 **动态规划（Dynamic Programming）**，这俩是以后 AI 路径规划和强化学习（RL）的绝对根基。必须亲手做 Python 版本的 Problem Sets。
    

### 🔵 阶段三：正式跨入 AI（建议耗时：3个月）

- **课程**：**6.036 (或 6.390) 机器学习导论**（前置数学：[[1 学习/MIT/MIT6.041/课程导学|6.041 概率]] + 18.06 线代）
    
- **行动指南**：这门课会将你前面的线代、概率论和算法**全部融合**。你会用 Python 从零手写感知机、SVM 和神经网络的前向/反向传播。
    

### 🔴 阶段四：选择你的专精领域（长期深入）

完成阶段三后，你已经具备了看懂大部分 AI 顶会论文的基础，接下来看兴趣选择：

- **喜欢偏底层理论** 👉 选 **6.046** (高级算法) + **6.867** (高级ML)
    
- **喜欢视觉与图像** 👉 选 **6.869** (计算机视觉)
    
- **喜欢物理控制与具身智能** 👉 选 **6.832** (机器人)
