##  1. 概率作为数学框架

概率论是**用于描述和处理不确定性**的严格数学框架。它让我们能够对随机现象建立模型，并进行定量预测。

---

##  2. 概率模型的两个组成部分

每个概率模型都包含两个要素：

| 要素 | 含义 |
|------|------|
| **样本空间** $\Omega$ | 所有可能Outcome的集合 |
| **概率律** | 给事件分配概率的规则 |

---

##  3. 样本空间 $\Omega$

- **集合**，包含一次随机试验的所有可能Outcome
- 必须满足：
  - **互斥**：Outcome之间不能同时发生
  - **完全穷举**：没有遗漏任何可能Outcome

### 离散示例：掷两次四面体骰子

$$\Omega = \{(x, y) \mid x \in \{1,2,3,4\},\ y \in \{1,2,3,4\}\}$$

共计 $4 \times 4 = 16$ 个Outcome。

### 连续示例：单位正方形中随机取点

$$\Omega = \{(x, y) \mid 0 \leq x \leq 1,\ 0 \leq y \leq 1\}$$

此时概率 = **面积**。

---

##  4. 事件

**事件**是样本空间的子集。概率律为每个事件分配一个概率值。

### 集合运算符号

| 符号 | 含义 |
|------|------|
| $A \subseteq \Omega$ | $A$ 是事件（样本空间的子集） |
| $A \cup B$ | 并事件（$A$ 或 $B$ 至少有一个发生） |
| $A \cap B$ | 交事件（$A$ 和 $B$ 同时发生） |
| $A^c$ | 补事件（$A$ 不发生） |
| $\varnothing$ | 空事件（不可能发生） |

---

##  5. 概率公理

概率律对每个事件 $A$ 分配一个数 $P(A)$，满足以下三条公理：

### 公理 1：非负性

$$P(A) \geq 0, \quad \forall \text{ 事件 } A$$

### 公理 2：归一化

$$P(\Omega) = 1$$

（必有一个Outcome发生的概率为1）

### 公理 3（有限可加性）：加法公理

若 $A \cap B = \varnothing$（$A$、$B$ 互斥），则：

$$P(A \cup B) = P(A) + P(B)$$

### 公理 3'（可数可加性）：可数加法公理

若 $A_1, A_2, \ldots$ 两两互斥，则：

$$P(A_1 \cup A_2 \cup \cdots) = P(A_1) + P(A_2) + \cdots$$

> **为什么需要可数可加性？** 在无限样本空间中做概率计算时必须用到（例如：计算可数无限个互斥事件的并概率）。

---

##  6. 简单例子

### 例 1：离散均匀律

当所有Outcome等可能时（公平硬币、公平骰子、充分洗牌的牌堆）：

$$\boxed{P(A) = \frac{|A|}{|\Omega|} = \frac{\text{事件 } A \text{ 包含的Outcome数}}{\text{样本空间总Outcome数}}}$$

### 例 2：连续均匀律

在 $[0,1] \times [0,1]$ 中均匀随机选点 $(X, Y)$，概率等于**面积**：

$$P(A) = \text{Area}(A)$$

- $P(X + Y \leq \tfrac{1}{2})$ = 底边为 $\frac{1}{2}$ 的直角三角形面积 $= \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$
- $P((X,Y) = (0.5, 0.3)) = 0$（单点面积为零）

### 例 3：可数无限样本空间

样本空间 $\Omega = \{1, 2, 3, \ldots\}$，设 $P(n) = 2^{-n}$。

**验证归一性：**

$$P(\Omega) = \sum_{n=1}^{\infty} 2^{-n} = \frac{1/2}{1 - 1/2} = 1 \checkmark$$

**计算Outcome为偶数的概率：**

$$P(\text{偶数}) = P(2) + P(4) + P(6) + \cdots = \frac{1}{4} + \frac{1}{16} + \frac{1}{64} + \cdots = \frac{1/4}{1 - 1/4} = \frac{1}{3}$$

---

##  7. 解题步骤

1. **确定**样本空间 $\Omega$
2. **定义**概率律
3. **识别**感兴趣的事件
4. **计算**概率

---

##  本讲要点

- 概率论是建立在三条公理基础上的**严格数学体系**
- 样本空间必须满足互斥性和完全穷举性
- 公理是一切概率规则的源头
- **可数可加性**对处理无限样本空间必不可少
- 均匀律（离散/连续）是最基础的概率模型
