# 核心假设

> 感觉-动作历史形成的self-state，比单帧本体观测更能表现视觉不可恢复的身体与交互状态

## 1.本体感知的不可替代性

$$\text{视觉+单帧本体观测}>\text{仅视觉}$$
在视觉相同、重量或摩擦不同的条件下，本体观测是否提供额外信息？
## 2.历史self-state的必要性

$$\text{历史self-state}>\text{单帧本体观测}$$
历史是否能推断单帧无法确定的负载、滑移趋势或执行器响应？
## 3.预测性学习的必要性
$$\text{预测式self-state}>\text{普通历史编码器}$$
提升究竟来自真正的预测结构，还是仅仅因为模型看到了更多历史数据？

# 限定self-state的具体内容

先只关注少量控制相关隐变量，例如负载、接触稳定性、滑移风险或执行器状态，避免再次扩张。

# 设计最小验证任务

选择视觉相同但物理属性不同的任务，比较机器人能否根据身体反馈适应重量、摩擦或外部扰动。

# 设定强基线和指标

对比视觉、本体状态拼接、原始历史编码、经典状态观测器和所提出的 self-state；测量预测误差、成功率、滑移和扰动恢复。
